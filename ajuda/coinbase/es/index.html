Cómo conectar tu Coinbase a BipView (solo lectura) — 3 minutos

Português · Español · English

La clave de Coinbase no se crea en la app de Coinbase ni en la configuración de la cuenta. Se crea en el portal de desarrolladores de Coinbase, con el mismo inicio de sesión. BipView solo lee: con el permiso correcto, nadie puede operar ni retirar con esa clave. Los nombres de los botones están en inglés porque el portal de Coinbase solo existe en inglés.

  1. Paso 1

    Abre la página de claves de Coinbase

    El botón abre el portal de desarrolladores de Coinbase directo en la página de claves. Entra con tu cuenta de Coinbase si te lo pide; si llegas al panel inicial, haz clic en el botón otra vez. En la pestaña Secret API keys, haz clic en Create secret API key.

    Abrir la página de claves de Coinbase ↗

    ¿No se abrió la página de claves? El camino por el menú

    Abre el menú (en el celular, el ☰ arriba; en la computadora, ya está a la izquierda), haz clic en Settings y luego en API Keys.

  2. Paso 2

    Ponle un nombre y restringe la clave a las IP de BipView

    En API key nickname, usa un nombre claro, por ejemplo BipView-Lectura. En IP allowlist, pega las dos direcciones de BipView, separadas por coma: 56.126.82.105, 56.126.93.102 (si el portal pide el formato con barra, usa 56.126.82.105/32, 56.126.93.102/32). Deja sin marcar “Allow requests from any IP address”. Así, aunque la clave se filtre, solo funciona desde los servidores de BipView.

  3. Paso 3

    Permiso: solo View (read-only)

    Abre Advanced settings. En Coinbase App & Advanced Trade, deja en Portfolio el portafolio donde están tus criptos (normalmente el principal) y deja marcado solo View (read-only) — ya viene marcado. No marques Trade, Transfer, Receive, Export ni Manage: BipView solo lee.

  4. Paso 4 · ⚠️

    El paso que traba: marca ECDSA y haz clic en Create

    Baja hasta Signature algorithm y marca ECDSA (Legacy SDKs). El portal viene con Ed25519 (Recommended) marcado y sugiere dejarlo así — para BipView, no: Coinbase no acepta claves Ed25519 para leer saldos. Si ya creaste una clave Ed25519, crea otra. Luego haz clic en Create y confirma el código que pida Coinbase.

  5. Paso 5

    Copia los DOS campos ahora

    Coinbase muestra dos campos: el API key name, que empieza con organizations/ y va hasta el código después de apiKeys/, y la Private key, el bloque entero de -----BEGIN EC PRIVATE KEY----- a -----END EC PRIVATE KEY-----. Copia cada uno entero. La Private key aparece una sola vez; si quieres guardarla, usa Download API key. (Este paso no tiene foto a propósito: la pantalla muestra la clave privada.)

  6. Paso 6

    Pégalos en BipView

    En la app BipView: pestaña Billeteras → botón + Exchange → busca Coinbase. Pega el API key name en el primer campo y la Private key en el segundo, y toca Conectar. Puedes pegar la Private key aunque las líneas queden juntas: BipView rearma el bloque. También puedes pegar el contenido entero del archivo descargado en uno de los campos. Si tu app muestra API Key y Secret Key (versión anterior), pega el API key name en el primero y la Private key en el segundo: funciona igual.

Si aparece un error

Mensaje en la appQué hacer
"Esta clave es Ed25519…"Crea otra clave y, en el paso 4, elige ECDSA (Legacy SDKs).
"El API key name no está completo…"Copia el campo entero, de organizations/ hasta el final.
"La Private key no fue reconocida…"Copia el bloque entero, del BEGIN al END.

Seguridad

Con solo View, BipView no puede operar ni retirar. La clave se cifra antes de guardarse y nunca aparece en pantalla. Puedes borrar la clave en el portal de Coinbase cuando quieras, y BipView deja de leer al instante.

Escribe a suporte@bipview.com contando en qué paso te quedaste. Nunca envíes tu Private key, ni siquiera a nosotros.
